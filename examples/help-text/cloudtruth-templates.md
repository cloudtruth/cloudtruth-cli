```console
$ cloudtruth templates --help
cloudtruth[EXE]-templates 
Work with Sigma Config templates

USAGE:
    cloudtruth[EXE] templates [SUBCOMMAND]

FLAGS:
    -h, --help       Prints help information
    -V, --version    Prints version information

SUBCOMMANDS:
    delete         Delete the Sigma Config template [aliases: del, d]
    differences    Show differences between templates [aliases: difference, differ, diff, di]
    edit           Edit the specified template [aliases: ed, e]
    get            Get an evaluated template from Sigma Config
    help           Prints this message or the help of the given subcommand(s)
    history        Display template history [aliases: hist, h]
    list           List Sigma Config templates [aliases: ls, l]
    preview        Evaluate the provided local template file without storing [aliases: prev, pre]
    set            Set the Sigma Config template [aliases: s]
    validate       Validate a Sigma Config template [aliases: valid, val, v]
```
